## 🚀 Featured Projects

### 1. [AI-Driven Threat Detection System](https://github.com/GIRISHKUSANURAMATH/AI-Driven-Threat-Detection-System)

A network threat detection system built using XGBoost and the UNSW-NB15 dataset, featuring leakage-aware evaluation, a FastAPI backend and a React security dashboard for alert investigation.

**Evaluation Results:**
- Attack Recall: 98.06%
- False-Positive Rate: 27.83%
- Evaluation Dataset: UNSW-NB15 test set.

**Status:** Provisional research model — lab evaluation only, not production-validated. Alerts are investigation leads, not confirmed security incidents.

**Technologies:** Python · XGBoost · FastAPI · React · Machine Learning · Network Security

### 2. [HybridRAG – Hybrid Retrieval-Augmented Generation](https://github.com/GIRISHKUSANURAMATH/HybridRAG-Hybrid-Retrieval-Augmented-Generation)

A hybrid retrieval system combining sparse and dense retrieval techniques with Reciprocal Rank Fusion (RRF) to improve document retrieval for LLM-powered applications.

**Technologies:** Python · RAG · BM25 · Dense Embeddings · RRF

### 3. [Privora – Privacy-Preserving Machine Learning Framework](https://github.com/GIRISHKUSANURAMATH/Privora)

A machine learning framework exploring privacy-preserving training techniques, including differential privacy and federated learning.

**Technologies:** Python · PyTorch · Opacus · Federated Learning · FastAPI

### 4. [EVALS – LLM Evaluation Framework](https://github.com/GIRISHKUSANURAMATH/EVALS)

An evaluation-focused project designed to test and assess LLM application behavior through structured datasets and automated evaluation workflows.

**Technologies:** Python · LLM Evaluation · SQLAlchemy · pytest

### 5. [LLMOps – Semantic Cache](https://github.com/GIRISHKUSANURAMATH/LLMops-semantic-cache)

A semantic caching project exploring similarity-based response reuse to reduce repeated LLM processing and improve application efficiency.

**Technologies:** Python · Semantic Search · Embeddings · LLMOps

### 6. [PyDB – Database From Scratch](https://github.com/GIRISHKUSANURAMATH/PyDB-Database-From-Scratch)

An implementation-focused database project exploring the internal concepts and engineering principles behind database systems.

**Technologies:** Python · Database Internals · Storage · Testing

### 7. [PyRedis – Redis-like In-Memory Database](https://github.com/GIRISHKUSANURAMATH/PyRedis-Redis-like-in-memory-database)

A Redis-inspired in-memory database implementation built to explore data structures, command execution and database behavior.

**Technologies:** Python · Data Structures · In-Memory Storage
